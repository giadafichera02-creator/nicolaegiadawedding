COME PUBBLICARE SU GITHUB + VERCEL

1. Scarica e decomprimi lo ZIP.
2. Nel repository GitHub elimina i vecchi file del sito:
   - index.html
   - styles.css
   - script.js
   - le vecchie foto e gli ZIP caricati per errore
3. Carica nella cartella principale del repository ESATTAMENTE:
   - index.html
   - styles.css
   - script.js
   - la cartella images completa
4. Premi Commit changes.
5. Vercel pubblicherà automaticamente il nuovo commit.
6. Apri il sito in incognito o premi Ctrl+F5.

IMPORTANTE:
- Non caricare lo ZIP direttamente nel repository.
- La cartella images deve restare accanto a index.html.
- I percorsi nel sito sono del tipo images/01-inizio.jpg.
